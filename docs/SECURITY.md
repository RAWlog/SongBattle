# Политика безопасности

В соответствии с правилами проекта, безопасность пользовательских данных и стабильность работы имеют высший приоритет.

## Ключи API
Проект спроектирован так, чтобы минимизировать использование сторонних API ключей. 
*   **Spotify:** Вместо `Client Secret` используется парсинг публичного HTML виджета, что исключает возможность компрометации токенов приложения.
*   **YouTube:** Используется `yt-search` (парсинг) вместо Data API v3, что защищает от переполнения квот (Rate Limiting и Quota Exhaustion) при злоумышленном использовании.

## Изоляция данных
Так как проект использует SQLite, база данных хранится локально в файле. Запрещено модифицировать архитектуру таким образом, чтобы локальные базы разных пользователей синхронизировались без их явного согласия. База данных не должна попадать в систему контроля версий (добавлено в `.gitignore`).

## Защита от CSRF и XSS
Использование Next.js App Router и Server Actions по умолчанию защищает приложение от большинства CSRF-атак. Весь пользовательский ввод (например, импорт из CSV) строго санируется перед вставкой в базу.
