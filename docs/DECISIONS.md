# Журнал архитектурных решений (ADR)

Здесь фиксируются ключевые решения, принятые в ходе разработки.

## 1. Отказ от официального Spotify API
*   **Дата:** Текущий релиз.
*   **Контекст:** Ограничения Developer Mode у Spotify API.
*   **Решение:** Переход на парсинг `Embed Widget` (до 100 треков) и импорт через `CSV` (безлимитно).

## 2. Использование архитектуры JIT (Just-In-Time) для YouTube
*   **Дата:** Текущий релиз.
*   **Контекст:** Парсинг 500+ видео с YouTube при старте турнира занимал минуты, приводил к тайм-аутам и блокировке IP.
*   **Решение:** Отложить поиск видео до момента рендера матча на экране пользователя. 

## 3. Очистка репозитория от мусора (Repository Hygiene)
*   **Дата:** Текущий релиз.
*   **Контекст:** Наличие временных скриптов, тестовых файлов и HTML дампов.
*   **Решение:** Строгое следование правилам `msg.txt`. Утверждено жесткое правило не хранить в корне временные и тестовые файлы, не относящиеся к E2E или Unit тестам.
