# Дорожная карта (Roadmap)

## Выполнено (MVP)
- [x] Парсинг Spotify плейлистов без API ключей.
- [x] JIT-поиск клипов на YouTube.
- [x] Математика турнирной сетки на любое количество треков (с BYE).
- [x] Рейтинговая система Elo.
- [x] UI в стиле Spotify (Tailwind v4).
- [x] Unit тесты для критической логики.

## Планируется в V2
- [ ] **Экспорт результатов:** Возможность сгенерировать плейлист из топ-10 треков по Elo-рейтингу и выгрузить его обратно в Spotify.
- [ ] **Многопользовательские турниры:** Позволить пользователям голосовать вместе в режиме реального времени через WebSocket.
- [ ] **Миграция на PostgreSQL:** Переход с локального SQLite на облачный PostgreSQL для возможности деплоя приложения на Vercel (потребует обновления Prisma Schema).
